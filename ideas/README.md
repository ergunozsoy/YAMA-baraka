# Oyun Bahçesi 🌳

Burada Irmak ve Deniz yaşar. Kurallar farklıdır: hata yapmak serbesttir,
saçma fikir yasak değildir, kimse puan vermez.

Her fikir bu klasöre bir Markdown dosyası olarak eklenir:

```markdown
# Fikrin adı

**Irmak'ın sorusu:** Ya ... olsaydı?
**Deniz'in oyunu:** ... şeklinde oynanabilir.
**Gelecek sinyali:** Bu bir gün ... için işe yarayabilir.
```

Buradaki hiçbir fikir otomatik olarak geliştirmeye dönüşmez.
Olgunlaşan fikirler elle değerlendirilir (v0.5'te Konsey ayda bir buraya bakacak).
